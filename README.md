# Student CRUD Operations

A full-stack Student Management System developed using **React.js** for the frontend and **Spring Boot** for the backend. The application allows users to perform CRUD (Create, Read, Update, Delete) operations on student records.

## 📌 Features

- Add Student
- View All Students
- Update Student Details
- Delete Student
- Responsive User Interface
- REST API Integration

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- Axios
- React Router DOM
- CSS

### Backend
- Spring Boot
- Java
- Spring Data JPA
- MySQL
- Maven

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/Umakant-17/Student-crud-operations.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

Backend runs on:

```
http://localhost:8080
```
